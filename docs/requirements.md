# 운동일지 Requirements

## 프로젝트 개요
개인 운동 기록 및 바디 트래킹을 위한 모바일 앱.
로그인 없이 로컬 데이터로 동작하는 단일 사용자 앱.

---

## 기능 요구사항

### 1. 운동 기록 ✅

#### 1-1. 부위 / 운동 라이브러리 ✅
- 기본 부위 제공 (가슴 / 등 / 하체 / 어깨 / 팔 / 복근) ✅
- 부위 직접 추가 / 삭제 가능 ✅
- 부위별 운동 목록 관리 (추가 / 삭제) ✅
- 기본 운동 목록 제공 (벤치프레스, 스쿼트, 데드리프트 등) ✅

#### 1-2. 운동 기록 흐름 ✅
- 운동 기록 화면에서 자유롭게 운동 추가 / 제거 ✅
- `+ 운동 추가` 버튼 → ExercisePicker 모달로 운동 선택 ✅
- 각 운동별 세트 / 무게(kg) / 횟수(reps) 입력 ✅
- 세트 추가 / 삭제 가능 ✅
- 각 운동별 메모(노트) 입력 칸 ✅

#### 1-3. 운동 세션 흐름 ✅
- `운동 시작!` 버튼: 세션 시작 → 우상단 경과 타이머 카운트업 (00:00) ✅
- 세션 상태(시작 여부, 시작 시각)는 Zustand에 저장 → 탭 이동해도 유지 ✅
- 운동 추가는 세션 시작 후에만 가능 ✅
- `완료` 버튼 (우상단): 세션 종료 → 운동 데이터 저장 ✅
- 저장 시 세션 총 소요 시간 함께 기록 ✅
- 완료 시 푸시 알림: "운동이 완료되었어요! 기록이 저장소에 저장됩니다." ✅
  - 웹: 브라우저 Notification API
  - 모바일: expo-notifications

#### 1-4. 세트 완료 체크 ✅
- 각 세트 옆 체크박스 제공 ✅
- 체크 시 해당 세트 흐리게 처리, 수정 불가 ✅
- 운동 카드에 "X/Y 세트 완료" 표시 ✅

#### 1-5. 1RM 자동 계산 ✅
- 마지막 세트 무게/횟수 기준 예상 1RM 자동 표시 (Epley 공식) ✅
- 각 운동 카드 하단에 "예상 1RM: Xkg" 표시 ✅

#### 1-6. PR(개인 기록) 자동 감지 ✅
- 종목별 역대 최고 무게를 실시간으로 비교 ✅
- 현재 세션에서 PR 갱신 시 🏆 PR 배지 표시 ✅

#### 1-7. 운동 노트 ✅
- 세션 전체 메모 입력 (컨디션, 특이사항 등) ✅
- 각 운동 종목별 개별 메모 입력 칸 ✅
- 저장 시 DB에 함께 기록 ✅

### 2. 운동 타이머 (세트 간 휴식) ✅
- 운동 기록 화면 좌상단 sticky 고정 (스크롤해도 항상 표시) ✅
- 축소 상태 (기본): 작은 pill 버튼, 상태별 색상 ✅
  - 대기: 회색 ⏱ 아이콘
  - 실행 중: 초록 + 남은 시간
  - 일시정지: 노랑 + 남은 시간
  - 완료: 빨강 0:00
- 탭 → 확장 패널, X 버튼으로 다시 축소 (타이머 백그라운드 진행) ✅
- 확장 패널: 프리셋 (30초/1분/1:30/2분/3분), 직접 입력, 시작/일시정지/재개/리셋 ✅
- 0이 되면 진동, 3초 후 자동 리셋 ✅
- 마지막 설정값 AsyncStorage 저장 ✅

### 3. 루틴 관리 ✅
- 루틴 생성: 이름 + 운동 선택 (부위 탭 → 운동 체크) ✅
- 루틴 목록 표시 (운동 개수, 종목 요약) ✅
- 루틴 삭제 ✅
- `이 루틴으로 시작 🔥`: 운동 자동 로드 + 세션 자동 시작 + 기록 탭 이동 ✅
- 루틴 ID 추적으로 신규 운동 vs 루틴 운동 구분 ✅

### 4. 통계 ✅
- 이번 달 운동 횟수 / 총 볼륨 / 전체 운동 수 요약 카드 ✅
- 이번 달 평균 운동 시간 ✅
- 주간 운동 횟수 바 차트 (최근 8주) ✅
- 종목별 최고 기록(PR) 목록 (금색 표시) ✅

### 5. 바디 트래킹 ✅
- 날짜 + 체중(kg) 입력 및 저장 ✅
- 당일 입력 시 기존 기록 덮어쓰기 ✅
- 최근 체중 카드 (큰 숫자) ✅
- 최근 14일 바 차트 ✅
- 전체 기록 목록 + 삭제 ✅

### 6. 운동 기록 수정 / 삭제 ✅
- 홈 화면 세션 카드에서 수정 버튼 → 수정 모달 ✅
- 제목 / 세트별 무게·횟수 / 운동 추가·삭제 수정 가능 ✅
- 기록 삭제 (확인 Alert 포함) ✅

### 7. 운동 캘린더 ✅
- 홈 화면 상단 월별 캘린더 ✅
- 운동한 날짜 보라색 하이라이트 ✅
- 오늘 날짜 테두리 표시 ✅
- 월 이동 (이전/다음) ✅
- 해당 월 운동 횟수 표시 ✅

### 8. 총 볼륨 표시 ✅
- 세션 카드: 총 볼륨 (무게 × 횟수 × 세트 합계) ✅
- 세션 카드: 총 운동 시간 ✅

### 9. 이전 세션 복사 ✅
- 홈 세션 카드에 `복사` 버튼 ✅
- 해당 운동을 기록 탭에 그대로 불러오기 (확인 Alert 포함) ✅

### 10. 데이터 백업 / 복원 ✅
- 통계 탭에서 전체 데이터 JSON export ✅
- JSON 붙여넣기로 데이터 복원 ✅

### 11. 운동 순서 드래그 정렬 ❌ (미구현)

- 웹(Chrome) / iOS / Android 동작 ✅

- 다크 모드 고정 (라이트 모드 전환 미구현) ❌

## 화면 구성

| 탭 | 내용 | 상태 |
|---|---|---|
| 홈 | 월별 캘린더 + 운동 기록 목록 (수정/삭제/복사) | ✅ |
| 기록 | 세션 시작/완료, 운동 추가, 세트 입력, 타이머 | ✅ |
| 루틴 | 루틴 목록, 생성, 시작 | ✅ |
| 통계 | 요약 카드, 바 차트, PR 목록, 백업/복원 | ✅ |
| 바디 | 체중 입력, 차트, 기록 목록 | ✅ |

## 데이터 모델

### WorkoutSession
| 필드 | 타입 | 설명 |
|---|---|---|
| id | string | timestamp+random 기반 ID |
| title | string | 운동 제목 |
| date | string | YYYY-MM-DD |
| exercises | ExerciseEntry[] | 종목 목록 |
| duration | number? | 세션 소요 시간 (초) |
| note | string? | 세션 메모 |

### ExerciseEntry
| 필드 | 타입 | 설명 |
|---|---|---|
| name | string | 종목명 |
| sets | SetEntry[] | 세트 목록 |
| note | string? | 종목별 메모 |

### SetEntry
| 필드 | 타입 | 설명 |
|---|---|---|
| weight | number | kg |
| reps | number | 횟수 |

### BodyPart
| 필드 | 타입 | 설명 |
|---|---|---|
| id | string | ID |
| name | string | 부위명 |

### Exercise (라이브러리)
| 필드 | 타입 | 설명 |
|---|---|---|
| id | string | ID |
| bodyPartId | string | 부위 FK |
| name | string | 운동명 |

### BodyWeight
| 필드 | 타입 | 설명 |
|---|---|---|
| id | string | ID |
| date | string | YYYY-MM-DD |
| weight | number | kg |

### Routine
| 필드 | 타입 | 설명 |
|---|---|---|
| id | string | ID |
| name | string | 루틴 이름 |
| exercises | RoutineExercise[] | 포함 운동 목록 |

### RoutineExercise
| 필드 | 타입 | 설명 |
|---|---|---|
| exerciseId | string | 라이브러리 Exercise FK |
| name | string | 운동명 |
| bodyPartId | string | 부위 FK |
| defaultSets | number | 기본 세트 수 |
