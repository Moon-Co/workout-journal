# 운동일지 Requirements

## 프로젝트 개요
개인 운동 기록 및 바디 트래킹을 위한 모바일 앱.
로그인 없이 로컬 데이터로 동작하는 단일 사용자 앱.

## 기능 요구사항

### 1. 운동 기록

#### 1-1. 부위 / 운동 라이브러리
- 기본 부위 제공 (가슴 / 등 / 하체 / 어깨 / 팔 / 복근)
- 부위 직접 추가 / 삭제 가능
- 부위별 운동 목록 관리 (추가 / 삭제)
- 기본 운동 목록 제공 (예: 벤치프레스, 스쿼트, 데드리프트 등)

#### 1-2. 운동 기록 흐름
- 운동 기록 화면에서 **자유롭게 운동 추가 / 제거** (단계 없음)
- `+ 운동 추가` 버튼 → ExercisePicker 모달로 운동 선택
- 각 운동별 세트 / 무게(kg) / 횟수(reps) 입력
- 세트 추가 / 삭제 가능

#### 1-3. 운동 세션 흐름
- **`운동 시작!` 버튼**: 세션 시작, 우상단에 경과 타이머 표시 (00:00 형식으로 카운트업)
- 세션 진행 중: 화면이 닫히지 않고 유지, 운동 자유롭게 추가/제거 가능
- **`완료` 버튼** (우상단): 세션 종료 → 운동 데이터 저장
- 저장 시 세션 총 소요 시간도 함께 기록
- 완료 시 **푸시 알림** 표시: "운동이 완료되었어요! 기록이 저장소에 저장됩니다."

### 2. 운동 타이머 (세트 간 휴식)
- 운동 기록 화면 **좌상단 sticky 고정** (스크롤해도 항상 표시)
- **축소 상태** (기본): 작은 pill 버튼, 상태별 색상 (대기: 회색 / 실행: 초록 / 일시정지: 노랑 / 완료: 빨강)
  - 대기 중: ⏱ 아이콘
  - 실행/일시정지/완료: 남은 시간 표시
- **탭 → 확장 패널**: 설정 + 컨트롤 UI 표시, X 버튼으로 다시 축소 (타이머 계속 진행)
- 확장 패널 내 기능:
  - 빠른 선택 프리셋: 30초 / 1분 / 1:30 / 2분 / 3분
  - 직접 입력: 분 + 초
  - 시작 / 일시정지 / 재개 / 리셋
  - 큰 글씨 남은 시간 표시
- 0이 되면 **진동** (소리 없음), 3초 후 자동 리셋
- **마지막 설정값 AsyncStorage에 저장** (앱 재시작해도 유지)

### 3. 루틴 관리
- 자주 쓰는 운동 루틴 저장/불러오기
- 루틴 생성, 수정, 삭제
- 루틴을 오늘의 운동에 적용

### 4. 통계 / 그래프
- 기간별 운동 횟수 시각화
- 종목별 무게 증가 추이
- 체중 변화 그래프

### 5. 바디 트래킹
- 날짜별 체중 기록
- 체중 변화 추이 그래프

### 6. 운동 기록 수정 / 삭제
- 저장된 운동 기록을 다시 열어 수정 가능
- 기록 삭제 가능

### 7. 1RM 계산기
- 무게 / 횟수 입력 시 예상 1RM 자동 계산 및 표시
- 종목별로 확인 가능

### 8. 세트 완료 체크
- 각 세트 옆에 체크박스 제공
- 완료된 세트는 시각적으로 흐리게 처리

### 9. 운동 순서 드래그 정렬
- 운동 기록 화면에서 종목 순서를 드래그로 변경 가능

### 10. 운동 캘린더
- 홈 화면에 월별 캘린더 표시
- 운동한 날짜 하이라이트

### 11. 총 볼륨 표시
- 세션당 총 볼륨 (무게 × 횟수 × 세트 합계) 자동 계산 및 표시

### 12. 개인 기록 (PR) 자동 감지
- 종목별 최고 무게 갱신 시 배지 또는 알림 표시

### 13. 이전 세션 복사
- 이전 운동 세션을 오늘 기록에 그대로 불러오는 기능

### 14. 운동 노트
- 세션 또는 종목별 메모 입력 (컨디션, 특이사항 등)

### 15. 데이터 백업 / 복원
- 전체 운동 기록을 JSON으로 export
- JSON 파일로 import하여 복원

## 비기능 요구사항
- 로그인/회원가입 없음 — 로컬 스토리지 기반
- 다크 모드 / 라이트 모드 전환 지원
- 오프라인 완전 동작
- Claude가 코드 변경 시 자동으로 git commit & push (GitHub: Moon-Co/workout-journal)

## 기술 스택 (확정)
- **프레임워크:** React Native + Expo SDK 54 (expo-router v6)
- **상태관리:** Zustand v5
- **로컬 저장소:** AsyncStorage (expo-sqlite는 웹 미지원으로 제외)
- **차트:** Victory Native
- **언어:** TypeScript

## 화면 구성
1. 홈 — 오늘 운동 요약 + 빠른 기록 시작
2. 운동 기록 — 종목/세트/무게/횟수 입력 ✅
3. 루틴 — 루틴 목록, 편집
4. 통계 — 운동 횟수·무게 그래프
5. 바디 트래킹 — 체중 입력 및 그래프

## 데이터 모델

### WorkoutSession
| 필드 | 타입 | 설명 |
|---|---|---|
| id | string | timestamp 기반 ID |
| title | string | 운동 제목 |
| date | string | YYYY-MM-DD |
| exercises | ExerciseEntry[] | 종목 목록 |

### BodyPart (부위)
| 필드 | 타입 | 설명 |
|---|---|---|
| id | string | timestamp 기반 ID |
| name | string | 부위명 (예: 가슴) |

### Exercise (운동 종목)
| 필드 | 타입 | 설명 |
|---|---|---|
| id | string | timestamp 기반 ID |
| bodyPartId | string | 부위 FK |
| name | string | 운동명 (예: 벤치프레스) |

### ExerciseEntry
| 필드 | 타입 | 설명 |
|---|---|---|
| exerciseId | string | Exercise FK |
| name | string | 종목명 |
| bodyPart | string | 부위명 |
| sets | SetEntry[] | 세트 목록 |

### SetEntry
| 필드 | 타입 | 설명 |
|---|---|---|
| weight | number | kg |
| reps | number | 횟수 |

### BodyWeight
| 필드 | 타입 | 설명 |
|---|---|---|
| id | string | timestamp 기반 ID |
| date | string | YYYY-MM-DD |
| weight | number | kg |
